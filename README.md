# Travel-Agency-Website-
Travel Agency Website 
Project Overview
Holiday Planner is a responsive travel agency website built using HTML, CSS, and JavaScript.
It allows users to explore destinations, view travel packages, and book trips through a contact form.

🚀 Features
🏠 Home page with hero section
📖 About page with company information
🌍 Destinations page with popular places
💼 Packages page with pricing and booking option
📞 Contact page with form validation and popup
🖼️ Image slider (carousel)
📱 Fully responsive design (mobile, tablet, desktop)
🛠️ Technologies Used
HTML5
CSS3 (Flexbox + Media Queries)
JavaScript (Form Validation + Slider)
